# Doodl AI Angular Wrapper

Angular workspace that publishes `doodl-ai-angular`, a standalone component for rendering [doodl.ai](https://doodl.ai/) charts.

## Scripts

```bash
npm install
npm start                 # demo app
npm run build:lib         # production library build
```

See the library README at `projects/doodl-ai-angular/README.md` for usage.
