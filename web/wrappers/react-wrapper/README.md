# Doodl AI React Wrapper

React workspace that publishes `doodl-ai-react`, a component for rendering [doodl.ai](https://doodl.ai/) charts.

## Scripts

```bash
npm install
npm run dev               # demo app
npm run build:lib         # production library build
npm run build:demo        # production demo build
```

See the library README at `projects/doodl-ai-react/README.md` for usage.
